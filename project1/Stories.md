# Selected Fragments
- “Had to create a new account.”
- “Why can I not see my past purchases?”
- “My review is not showing up.”
- “Transaction shows complete but no product access.”
- “Session expired while I was active.”
- “Product ID does not match anything.”

# User Stories
- As a user, I want to create and use only one account, so I do not have to waste time managing multiple login credentials.
- As a user, I want to see all my past purchases, so I can easily find products I want to review or purchase again.
- As a user, I want to share my thoughts on a product, so other users can determine if the product meets their needs.
- As a user, I want my products to be accessible upon transaction completion, so that I can verify product receipt.
- As a user or vendor, I want my session to stay active while interacting with the system, so I do not get interrupted and need to log back in.
- As a vendor, I want all my products assigned a unique Product ID, so users can reliably find my wares.
